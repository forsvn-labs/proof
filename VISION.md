# Proof fork vision

Maintain a local, inspectable Markdown editor and agent bridge for authors,
human reviewers, and Conquistador-assisted document work. Preserve Proof
SDK's editing, provenance, comments, suggestions, and collaboration model
while adding channel previews and review of one exact document revision.

## Outcomes and scope

A reviewer can inspect channel framing, playbooks, and findings, then stamp
an exact text hash in the browser. Edits invalidate that stamp. The local
server and agent bridge keep document state inspectable. Maintain upstream
MIT attribution and trademark boundaries; keep fork behavior documented
separately from upstream behavior.

## Non-goals

A review stamp does not authorize sending, publication, spending, or a
canonical verdict change. This fork does not claim to operate Every's
hosted Proof service. Review integration stays local; new fork features
require a concrete need or upstream integration decision. Current work
and limits live in [STATUS.md](STATUS.md).
